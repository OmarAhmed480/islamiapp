# 🕌 Islami App

A modern and beautifully designed **Islamic Flutter Application** that brings essential Islamic resources together in one simple and interactive experience.

The application provides access to the **Holy Quran, Hadith, Sebha, Prayer Times, Azkar, and Islamic Radio**, with a custom Islamic-themed interface, responsive layouts, and smooth navigation.

---

## ✨ Features

### 📖 Quran

- Browse all **114 Surahs**
- Read Quran verses
- Search for Surahs
- View detailed Surah content
- Recently viewed Surahs
- Quick access to recently opened Surahs
- Local Quran data

### 📜 Hadith

- Browse Islamic Hadith
- Interactive Hadith cards
- Local Hadith data
- Clean and readable Hadith interface

### 📿 Sebha

- Digital Tasbeeh counter
- Interactive counting
- Counter state management
- Custom Sebha interface

### 🕌 Prayer Times & Azkar

- Prayer Times interface
- Prayer cards
- Prayer date header
- Azkar cards
- Islamic-themed design

### 📻 Islamic Radio

- Multiple Islamic Radio channels
- Play / Pause controls
- Volume controls
- Interactive Radio interface

### 🎨 UI & UX

- Modern Islamic-themed design
- Custom colors
- Custom fonts
- Custom icons and backgrounds
- Responsive layouts
- Reusable widgets
- Smooth navigation
- Custom Splash Screen
- Intro / Onboarding screens

## 💾 Local Data Management

The application uses local assets and **SharedPreferences** to manage application data.

### Quran & Hadith

Quran and Hadith content are stored locally inside the application assets.

### Recently Viewed Surahs

The application saves recently viewed Surahs locally using **SharedPreferences**, allowing users to quickly access their recent Quran activity.
